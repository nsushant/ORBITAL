# ORBITAL project papers

This branch contains publication records associated with the ORBITAL research
project. Each paper should have its own directory containing either the
publication PDF or a short Markdown file linking to the publisher and the
corresponding reproducibility release.

## Planned publications

### Multi-objective mission planning for depot-supported on-orbit servicing

- Status: manuscript in preparation
- Code and data: [`paper/oos-mdls`](https://github.com/nsushant/ORBITAL/tree/paper/oos-mdls)
- Publication: link to be added when available

## Suggested layout

```text
papers/
└── oos-mdls/
    ├── README.md
    └── manuscript.pdf
```

Use stable filenames without manuscript section or version numbers. Where a
publisher permits only a link rather than redistribution of the published PDF,
store the DOI and publisher URL in the paper's `README.md` instead.
